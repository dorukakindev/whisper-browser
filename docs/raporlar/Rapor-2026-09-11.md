## YÜKSEK

### Y-1 — HLS `EXT-X-DISCONTINUITY` sonrası byte-range state sıfırlanmıyor
- **Kanıt:** `src/browser-subtitles.js:393-396` (`parseHlsSegments`)
- **Mekanizma:** `#EXT-X-DISCONTINUITY` tag'i `discontinuity += 1` yapıp `continue` ediyor. Implicit `#EXT-X-BYTERANGE` continuation state'i (`previousByteRangeUrl`, `previousByteRangeEnd`) temizlenmiyor. Aynı URI ile explicit-offset olmadan gelen segment, satır 402-404'teki `url === previousByteRangeUrl` eşleşmesiyle önceki parçanın bittiği byte'ın ardından devam eden yanlış offset alıyor. main.js bu offset'i `fetchBrowserBufferWithRetry(segment.url, …, segment.byteRange)` ile HTTP Range isteğine çeviriyor → 416 ya da yanlış byte aralığı → bozuk/kırpılmış altyazı.
- **Etki:** wvtt/stpp canlı yayınlarda discontinuity sonrası ilk parça boş/yanlış; özel manifest'lerde kalıcı bozuk altyazı.
- **Fix:** Discontinuity branch'inde `previousByteRangeUrl=''; previousByteRangeEnd=0;` ekle.
- **Test:** `tests/browser-subtitles.test.js:415` yalnız `discontinuity` sayacını sınar, byte-range kombinasyonu yok.

### Y-2 — `browser:trusted-bridge` whitelist'inde `page-action` yok → sayfa araç çubuğu ölü
- **Kanıt:** `src/browser-preload.js:11` whitelist = `['manga-edit', 'overlay-style', 'page-blocks', 'reading-position']`. `src/main.js:9361` `else if (message.type === 'page-action')` route var, `src/browser-page-translate.js:932` `send('page-action', …)` gönderiyor.
- **Mekanizma:** Whitelist reddi yüzünden `__whisperTrustedBridgeSend('page-action', …)` `false` döner, IPC ulaşmaz. Orijinali gör / Yeniden çevir / Düzelt / Düzeltmeyi sitede hatırla / Bu bölümü çevirme butonları ile çeviri başarısız rozeti tıklamaları ölü.
- **Etki:** Kullanıcı çeviri düzeltme, "bu bölümü atla" ve "yeniden dene" işlemlerini yapamaz.
- **Fix:** Whitelist'e `'page-action'` ekle.
- **Test:** kapsamı yok.

### Y-4 — `estimateVramMib` pyannote underestimate → 12 GB'da OOM uyarısı hiç çıkmaz
