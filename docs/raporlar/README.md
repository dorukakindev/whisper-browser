# Denetim ve araştırma raporları

Proje kökünü sade tutmak için tarihsel denetim, bug avı, öneri ve doğrulama raporları burada durur.
Yeni raporları da buraya ekleyin (bkz. `AGENTS.md`).

- `BROWSER_BUG_REPORT_<n>.md` — numaralı tarayıcı bug raporları
- `BROWSER-*-DENETIM-*.md`, `*-DOGRULAMA-*.md` — tarihli denetim ve doğrulama turları
- `FEATURE_*.md`, `BROWSER_FEATURE_RESEARCH_*.md`, `ENTEGRASYON-PLANI.md` — öneri katalogları ve planlar
- `PROGRAM_BUG_REPORT_<n>.md`, `Rapor-*.md`, `13.09.2026.*.md` — eski tur notları
