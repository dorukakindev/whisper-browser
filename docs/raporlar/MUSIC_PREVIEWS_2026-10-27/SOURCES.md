# İnternet müzik önizlemesi kaynakları

27 Ekim 2026. Yeni SDK veya üçüncü taraf kod kopyası eklenmedi.

- [Musicmeta](https://github.com/famesjranko/musicmeta), Apache-2.0: mevcut R662 incelemesinin DeezerApi/Provider/Mapper kaynakları yeniden okundu. Açık kayıt kimliği, taze preview ve sağlayıcı ayrımı kullanıldı. Kotlin bağımlılığı alınmadı. Önceki kaynak hashleri `../MUSIC_ONLINE_2026-10-27/upstream-files.json` içinde.
- [Deezer API kullanım koşulları](https://developers.deezer.com/termsofuse): özel kullanım ve 30 saniyelik önizleme sınırı; tam kayıt veya DRM aşma uygulanmadı. API ve önizleme erişiminin ülke/sağlayıcıya bağlı olduğu kabul edildi. Yeni hesap/anahtar/ücretli servis kullanılmadı.
- [CLAP model kartı](https://huggingface.co/laion/clap-htsat-unfused), Apache-2.0: mevcut sabitlenmiş `8fa0f1c6d0433df6e97c127f64b2a1d6c0dcda8a` revizyonu ve mevcut yerel motor kullanıldı. Yeni model indirilmedi.
- [Openverse](https://github.com/WordPress/openverse) alternatifi kontrol edildi; API doküman isteği bu ortamda 403/erişim engeli verdi. Çalıştığı iddia edilmedi ve bağımlılık alınmadı.

Model çıktısı bir beğeni olasılığı değildir. Önizlemeler tam eserin ses benzerliğini kanıtlamaz. Katalog adayları üzerinde yeniden sıralama yapılır; evrensel internet indeksi kurulmadı.
