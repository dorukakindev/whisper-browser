# D841 kaynak değerlendirmesi ve sınırlar

## Gerçek kapsam

1 Kasım 2026'da dokuz esas depo ve bir ek eleme adayı incelendi. Güncel varsayılan dalın tam HEAD'i `repositories.json` içindedir; kararlı release seçimi veya çalıştırma kabulü değildir. GitHub REST tree yanıtlarının hiçbiri truncated değildi. Kök lisans dosyaları ve seçilmiş gerçek fonksiyonlar incelendi; README vaatleri çalışan ürün kabulü yapılmadı. Yeni ürün bağımlılığı, servis, model, test ayarı veya kişisel profil değişmedi. Kamu kaynak dosyaları yalnız ignored cache'tedir; yayımlanan pakette üçüncü taraf kaynak gövdeleri/dataset yoktur.

R838, R839, R840 ve güncel devir 1447 okundu. R839-F01–F12'nin tamamı yenilik sayımından ayrıldı. 24 kartın 12'si yeni kullanıcı sonucu, 12'si mevcut fikir/özelliğin derinleştirmesidir. Bu ayrım bütün tarihsel raporlardaki yüzlerce önerinin eksiksiz semantik taraması iddiası değildir. Bu bir bug denetimi olmadığı için Night1000'deki eski senaryolar yeniden koşulmadı veya yeni bug sayılmadı. Yerel ürün değişmedi; ürün testleri/UI/start.bat çalıştırılmadı. Windows hakkındaki değerlendirme paketleme ve kod mimarisi düzeyindedir.

## Kaynaktan hazır gelmeyen kısımlar

D841-01'de çapraz sağlayıcı entity merge, D841-04'te franchise completion, D841-07'de ortak ekip grafiği, D841-08'de liste delta/provenance, D841-11'de undo snapshot, D841-13'te counterfactual, D841-14'te aktif soru seçimi ve D841-19'da replay artifact'i yeni uygulama tasarımlarıdır. Verilen upstream fonksiyonlar bunların yapı taşlarıdır, tamamlanmış aynı özelliğin varlık kanıtı değildir. Kartlarda bunun özellikle belirtilmesi README'den özellik uydurmaktan kaçınmak içindir.

D841-21 ve D841-22 dış depodan hazır spoiler/duygu modeli alımı değildir; yerel kaynak sözleşmesinin ve önceki R839-F08'in derinleştirilmesidir. Bu iki kart dış kaynak keşfi sayısına eklenmemeli. Otomatik spoiler sınıflandırıcı, nesnel yorum doğruluğu veya gerçek kullanıcı memnuniyeti bu araştırmada doğrulanmadı.

## Veri ve Windows sınırı

Keşfet'in hesabı/anahtarı olmayan Cinemeta yolu korunabilir; TMDB zenginleştirmeleri mevcut opsiyonel credential sistemine bağlıdır. Ülkesel provider metadata'sı abonelik oturumunu, gerçek oynatma hakkını, Türkçe altyazıyı veya DRM'yi kanıtlamaz. Dış metadata/dataset koşulları açık kaynak kod lisansından ayrıdır. Kişisel Letterboxd profili veya private veri kullanılmadı.

Node22.13+ için küçük portlar en düşük işletim maliyetidir. Python deneyleri CPython3.10/3.11 ve ayrı ortam gerektirir; GPU modeli indirmek gereksizdir. Gerçek Windows kabulü uygulanacak kart başına start.bat, dosya seçici/UTF-8, dar ekran/DPI ve gerekiyorsa yardımcı süreç kapanışını içermelidir. Bu rapor o kabulü yapmış sayılmaz. Hiçbir araç uzaktan çalıştırılmadı/kurulmadı.

## QA ve bilinen okuma aksaklıkları

İlk sandbox public HTTP okumaları SSL engeli verdi; public-read escalation sonrası REST/raw okuma çalıştı. Streamyfin kişi dosyası indirildikten sonra PowerShell wildcard `[personId]` yüzünden hash metadata kaydı ilk seferde başarısız oldu; Python literal Path ile aynı indirilen dosyanın hash kaydı tamamlandı. Bu ürün hatası veya eksik kaynak okuması değildir.

Kaynak bağlantıları tam HEAD'e sabittir; SHA256 dosya byte hashleri taşınır. Yerel kaynak hashleri UTF-8 BOM çözme ve CRLF→LF normalizasyonu ile kaydedildi. Markdown/JSON içerik ve kart ID/yenilik/kelime uzunluğu kontrolleri yapıldı. Ürün regresyon testleri yapılmadı çünkü ürün kodu değişmedi. Parent ajan nihai rapora alınacak kartları alanlar arası tekrar denetiminden geçirmelidir; bu alt paket kendi başına commit/push edilmedi.
