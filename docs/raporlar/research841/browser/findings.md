## Mevcut ürünü doğru başlangıç kabul etmek

`browser-library-tools.js` zaten birleşik arama, koleksiyon üyeliği/sırası ve exact/prefix/suffix/DOM-path/position ile metin ankrajı yapıyor. `watch-index.js` SQLite FTS içeriyor. `browser-reading-list.js` zaten uygulama içi MHTML arşivi, yeniden kaydetme ve güvenli dosya adı/yazımı içeriyor. `browser-session-store.js` v8 sekme, grup, okuyucu ve iş kurtarma bilgisi tutuyor; `browser-session-package.js` workspace dışa aktarabiliyor. `browser-tab-resources.js` oynayan/iş yapan/kaydedilmemiş sekmeleri koruyor. `browser-site-permissions.js` origin bazlı izinler ve medya türü ayrımı yapıyor. Dolayısıyla “arama/koleksiyon/arşiv/sekme grubu/izin ekleyelim” bu raporun önerisi değildir.

`assistant-browser-research.js:createResearch` arama motorlarını sırayla dener, dört URL toplar, ilk üçünü okur, pasajı 6000 karakterde keser ve kısmi kamusal kapsamı açıkça söyler. Önerilerin önemli kısmı bu zaten çalışan dar hattı daha seçilebilir ve kanıtı korunur hale getirmek içindir. Kök nedenli bug incelemesi yapılmadı.

AGPL resolver fikri kendi main sınırında bağımsız veya uyumlu port olur; sunucu kullanıcı sistemi taşınmaz. **Kabul:** bilinmeyen ID, silinmiş revizyon, profil dışı ref ve unsupported format açık hata; yol sızmaz. Windows case/UNC/symlink sınırları mevcut güvenli store ile doğrulanır; renderer genel dosya açma yetkisi kazanmaz.

## Kaynaklı araştırmanın kapsamı ve doğruluğu

### B841-16 — Sağlayıcı sorgusundan sonra da zorlanan kaynak filtreleri

**NEW / S–M.** `assistant-browser-research.js:createResearch` motor sonuçlarından güvenli URL toplar; kullanıcı alan adı/başlık/yol kısıtını ortak bir sözleşme olarak taşımıyor. Firecrawl [operators.parseQueryOperators/planOperatorQuery](https://github.com/firecrawl/firecrawl/blob/7e6bd701febaacc3bb95c0fb7eee2c509a4813c5/apps/api/src/search/operators.ts) site/intitle/inurl ve negatiflerini ayrıştırır; sağlayıcının tutarsız uyguladığı operatörleri sonuç üzerinde denetleyecek plan üretir. “Yalnız resmî röportajlar, forum yok” araştırmasında filtreler görünür çip olur; sonuç sınırı gerçekten uygulanır. AGPL uyumlu küçük TS port veya bağımsız parser; Firecrawl servisi şart değil. **Kabul:** site:example.com evil-example.com'u kabul etmez, IDN/domain yolu, tırnak içi literal ve desteklenmeyen OR dürüstçe ele alınır. Ağ/URL doğrulaması main'de, filtre gevşetme otomatik olmaz; Windows/CSP etkisi düşük.

### B841-17 — Kaynak sayısından ayrı sayfa derinliği ve gezinme grafiği

**OLD-DEEPENING R839-A06 / M–L.** Yerel araştırma ilk üç URL'yi okur; derin araştırma modu önceki raporda zaten önerildi. Crawl4AI [BFS.link_discovery](https://github.com/unclecode/crawl4ai/blob/888299fb5f0b82181897dc0e61bfb4b036f0aea5/crawl4ai/deep_crawling/bfs_strategy.py) max_depth, max_pages, visited, parent URL, cancel ve kapasiteyi ayrı tutar. Somut derinleştirme: bir yönetmenin resmî röportaj sayfasından seçili bağlantılara en fazla bir adım ilerle; “3 kaynak / 5 sayfa / derinlik1” kapsamını ayrı göster. Tam crawler kurmak yerine Apache BFS/kota veri modelini araştırma main servisine port etmek yeterli olabilir. **Kabul:** A↔B döngüsü kota aşmaz, kullanıcı iptali yeni navigasyonu durdurur, her son kaynak hangi sayfadan keşfedildiğini gösterir. Windows native sekmeler bağımsız worker kapsamındadır; açık kullanıcı sekmelerinde sessiz gezinilmez.

### B841-18 — Hangi bağlantıyı önce okuyacağını gerekçeli seçme

**OLD-DEEPENING R839-A06 / M.** `createResearch` ilk okunabilir motorun sırasını takip eder; `browser-omnibox.js` kullanıcı aramasını farklı motorlara açabilir. Crawl4AI [CompositeScorer/KeywordRelevanceScorer/PathDepthScorer](https://github.com/unclecode/crawl4ai/blob/888299fb5f0b82181897dc0e61bfb4b036f0aea5/crawl4ai/deep_crawling/scorers.py) link adayına farklı ağırlıkları birleştirir. Geliştirme “en iyi kaynak” iddiası değil: resmî domain, sorudaki konu ve belge türüne göre okunacak üç sayfayı seçme; nedenini kullanıcıya küçük etiketle açıklama. Tarihten doğruluk çıkarılmaz; URL yıl regex'i güvenilir yayın tarihi değildir. Apache saf skor portu, model çağrısı gerektirmez. **Kabul:** aynı domain sonuçların hepsini işgal etmez, kullanıcı sabitlediği kaynak korunur, bilinmeyen domain düşük kesinlikli kalır. Main'de skor, renderer'da salt sonuç; Windows bağımlılık ve CSP ek yükü yok.

### B841-19 — İlk 6000 karakter yerine soruyla ilgili pasajlar

**OLD-DEEPENING R839-A05 / M.** `createResearch` metni 6000 karakterde baştan kesiyor; `browser-page-index.js` çıkarılmış blokları indekse verir. Crawl4AI [BM25ContentFilter.filter_content](https://github.com/unclecode/crawl4ai/blob/888299fb5f0b82181897dc0e61bfb4b036f0aea5/crawl4ai/content_filter_strategy.py) blokları soruya göre puanlar, tag ağırlığı uygular, seçtiklerini belge sırasına geri dizer ve tekrarları ayıklar. Mevcut Defuddle'ın yerine ikinci okuyucu koymak değil, onun blokları üzerinde soru odaklı bağlam seçmek önerilir. “Röportajın sonundaki kurgu açıklaması” baştan kesilerek kaybolmasın. Apache algoritma Node'a port edilebilir; English stemming kör taşınmaz. **Kabul:** sona gömülü bilinen pasaj gelir, alıntı aslına döner, düşük skor boş kanıtı uydurma özetle doldurmaz. Windows worker zaman/bellek bütçesi ve EN/TR corpus ölçümü gerekir; kalite garantisi bu araştırmada yoktur.

### B841-20 — Tablo ve listeyi bozmayan alıntı parçaları

**OLD-DEEPENING R839-A05/F08 / M.** `researchAnnotationsToMarkdown` seçili alıntıyı düz metin olarak aktarır; `createResearch` pasajlara W kimliği koyar. Bizde karşılaştırma tablosundan alınan bir veri başlıksız kalmasın; cümle alıntısı başka blokla tek iddiaya dönüşmesin. AGPL seçilmiş parser uyarlaması mümkündür; ona bağlı model/threshold alınmış sayılmaz. **Kabul:** Türkçe kısaltma, pipe içeren hücre, ardışık olmayan satır ve başlıksız tablo fixture'ları; çıktı kaynak span ID'sini korur. Güvenli Markdown renderer/CSP değişmez, code fence çalıştırılmaz. Windows satır sonları kanıt offset'leriyle normalize edilir.

### B841-21 — Aynı URL'yi tekrar okumayla yeni araştırma niyetini ayırma

**OLD-DEEPENING R839-A05/A07 / S–M.** `createResearch` aynı koşuda URL eşitliğiyle dedup yapar; `browser-reading-list.js` canonical URL başına kaydı yeniler. ### B841-22 — Kaynak güncelliğini “değişmedi / değişti / bilinmiyor” diye ayırma

Apache saf host kuyruğu portu uygundur, Python dispatcher kurulması gerekmez. **Kabul:** 429 sonrasında aynı host baskılanır, başka host sürer, iptal tüm timer'ları bırakır; 403/hesap doğrulaması sonsuz retry olmaz.
