# Devir Notu — 2026-09-27 12:00 (R155 .bat statik denetimi)

## Kapsam
R155: install.bat/start.bat/yardımcı .bat dosyalarının statik denetimi. 2 gerçek Windows UX bug'ı düzeltildi.

## Bug'lar
1. **start.bat `setlocal` eksik** — HF_*/TRANSFORMERS_*/PYTHONWARNINGS ve PATH ön eklemeleri çağıran cmd oturumuna sızıyordu; aynı konsolda art arda start.bat koşusu PATH'i her seferinde üç girdi daha şişiriyordu. `setlocal` eklendi (alt süreç npm start ortamı etkilenmez; setlocal yalnız batch kapsamını kapatır).
2. **Yardımcı kurulum .bat'lerinde pause'suz hata çıkışı** — install-browser-align.bat / install-browser-tools.bat / install-browser-extras.bat'da `exit /b 1` yollarında `pause` yoktu; Explorer'dan çift tıkla başlatılan başarısız kurulum hata mesajını göstermeden pencereyi kapatıyordu. Tüm `exit /b 1` yollarına `pause` eklendi; extras'taki tek satırlık `if errorlevel 1 exit /b 1`'ler açıklayıcı echo'lu bloklara çevrildi.
