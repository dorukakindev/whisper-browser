# Handoff — 2026-09-17 07:46 · Full-track subtitle translation context

## Summary

The latest source/translation pair in `Downloads\Whisper\ÇIKTI` was reviewed by timestamp rather than cue number. Its 85 source cues and 85 translated cues were structurally complete, but the translation sounded literal and frequently lost sentence grammar because long literary sentences were split into separate provider requests. This was a provider-independent orchestration problem, not proof that CodeCraft itself was the sole cause.

## Evidence

- The pair audit reported 85/85 timestamp-matched cues, no missing or extra output, no source echo, and no number mismatch. It passed because those checks establish structural integrity; they do not prove natural Turkish.
- The reviewed output contained literal or incomplete constructions such as duplicated `nasıl`, `Mantıksal Avrupa`, `suçlarını ... kuluçkalasın`, `Büyük T ile. Akıl.` and sentence fragments whose predicates arrived in later cues.
- With the previous production limits, the 85-cue source became 81 translation units and only four units contained more than one cue.
- The final bounded full-track policy produces 62 translation units, including 16 multi-cue units. It groups source cues 1–3, 4–6, 7–9, 10–11, 16–17 and other conservative continuation/list cases without changing any cue timestamp or cue count.

## Changes

- `src/browser-translation-scheduler.js`
  - Extracted lossless sentence construction into one helper.
  - Added an opt-in completed-track pass for explicit English dependent fragments and short possessive-list/predicate sequences.
  - Kept live/growing subtitle defaults unchanged so translation latency does not increase while a sentence is still arriving.
  - Added gap, duration, character, part-count and speaker-boundary limits to every new merge.
- `src/main.js`
  - Completed subtitle tracks now use a bounded 1.8-second gap, 32-second duration, 520-character and eight-part semantic window.
  - Turkish browser subtitle requests now receive the measured natural-language guidance already used by the backend refinement design: reconstruct the whole sentence in Turkish, omit redundant pronouns safely, prefer idiomatic collocations and preserve the source register.
  - Browser subtitle prompt identity moved to `browser-sentence-v3-natural-context`, preventing old prompt-cache entries from masking the change.
- `tests/subtitle-sentence-layout.test.js`
  - Added long complete-track, list/predicate, dependent-fragment and false-merge regressions.
  - Added assertions against the real main-process request body for the natural Turkish guidance.

## Limits and follow-up

- No live provider request was made in this work. The orchestration and prompt contract are verified, but the exact wording produced by CodeCraft, 4SAPI or another provider still requires a new translation run.
- Existing `.tr.srt` files were not rewritten. Use **Translate entire track with a new model** (or otherwise start a fresh translation) so the v3 prompt and new grouping produce a new result.
- The broad full-track window is intentionally not applied to live/growing captions; live captions retain the low-latency bounds.
- This change adds no dependency, IPC permission or persistent-file schema.
