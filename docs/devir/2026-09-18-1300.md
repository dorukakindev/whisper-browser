## Yapılan değişiklikler

### Backend (yeni)
- `backend/invidious.py` — Invidious API istemcisi
  - 5 varsayılan instance (yewtu.be, privacyredirect, projectsegfau.lt,
    vid.priv.au, inv.nadeko.net) — sırayla denenir, çalışan cache'lenir
  - `extract_video_id`: 7 URL pattern'i (watch, youtu.be, embed, shorts,
    bare ID, query param, hata durumu)
  - `probe`: video bilgisi + adaptive streams (video/audio itag'lı),
    HLS/DASH manifest, captions listesi, bölümler

## Tasarım kararları

- **Geriye dönük uyumluluk**: yt-dlp yolu varsayılan kalır (playerSource='ytdlp').
  Mevcut kullanıcıların davranışı değişmedi. Invidious opt-in.
- **Fallback**: Invidious başarısız olursa yt-dlp'ye otomatik düşüş yok —
  kullanıcı bilinçli seçim yapar (kaynak dropdown'ı).
- **Güvenlik**: decideUrlPolicy javascript:/file:/data: reddeder; sadece
  http/https. URL'ler renderer'da değil main'de doğrulanır.
- **Session yok**: Invidious sunucu taraflı auth gerektirmez, bot koruması
  yok. yt-dlp'ye kıyasla çerez/oturum seçeneği gerekmez (cookieBrowser
  parametresi Invidious yolunda kullanılmıyor).
- **Yazılan altyazılar SRT, UTF-8 BOM** — mevcut subtitleFileAccess.grant
  üzerinden renderer'da okunabilir (decodeSubtitleBuffer uyumlu).

## Sınırlar / kalan iş

- **Network call'lar live test edilmedi** — Invidious instance'ları
  çevrimdışı ortamda test edilmedi. Hata yolu kodlandı ama gerçek
  bağlantı kurulup probe yapılmadı. Kullanıcı canlı denemede Invidious
  çalışmıyorsa yt-dlp'ye dönebiliyor.
- **Invidious session yok** — bazen YouTube'un yaş/bot kontrolüne takılır;
  bu durumda Invidious captions API'si boş döner, timedtext ise başarılı
  olabilir. Kullanıcı yorumla karşılaşırsa yt-dlp'yi seçmesi gerekir.
- **HLS akışları Invidious adaptiflere tercih edilmedi** — yt-dlp yolu
  HLS'i yerel player ile oynatır; Invidious yolunda adaptive streams
  (ayrı video/ses) kullanılır, basit <video src> ile çalışmaz. Tam
  HLS oynatma Invidious tarafında ek iş gerektirir.
- **Altyazı dönüşümü minimal** — timedtext format 3 (srv3) ve daha
  gelişmiş formatlar test edilmedi; srv1 en temel olan.
