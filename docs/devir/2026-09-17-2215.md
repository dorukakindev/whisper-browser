## Changes

### `tests/manga-layout-state.test.js`

The minimal DOM style double now provides browser-like `setProperty`,
`getPropertyValue`, `getPropertyPriority`, and `removeProperty` behavior. The
test also verifies that the injected manga overlay's critical position and
pointer-event declarations keep their `important` priority. This fixes the
false failure caused by production's correct use of `CSSStyleDeclaration`.

### `tests/electron-a3-acceptance.smoke.js`

CDP WebSocket clients now receive a bounded close handshake. After all
test-owned sockets, Electron processes, HTTP server connections, and temporary
directories have been cleaned, the standalone smoke process exits explicitly
with code 0. This prevents the runner from waiting for its 15-minute timeout
after the acceptance assertions already passed.

### `tests/media-catalog-service.test.js`

The real registered IPC handler now proves the imported local-media contract:

- canceling the native picker grants nothing and leaves the imported marker;
- confirming grants only the selected native path;
- the selected path replaces the package-provided path and clears the marker;
- a later nMDB import cannot overwrite the user-confirmed local source.

### `tests/workspace-restore-regressions.test.js`

The source-text regex for the service layer was removed. This test retains the
package restoration and store round-trip boundary, while the media catalog
service test owns executable picker/cancel/grant behavior.
