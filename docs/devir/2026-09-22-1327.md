## Bulunan kök nedenler (BROWSER_BUG_REPORT_106)

1. **F-106-1a — `.st-card-thumb` aspect-ratio çöküşü:** `.st-card` `display:flex; flex-direction:column`; içindeki `aspect-ratio:16/9` div, Chromium'nin flex çözümünde cross-size belirsizken main-size=0'a düşüyor → thumb 0px. Kartlar tasarım gereği şeffaf + border'sız → thumb olmadan "hiçbir şey görünmüyor". CDP'de doğrulandı: thumb rect height 0; aynı dokümanda standalone div aynı aspect-ratio → 168.75; `display:grid`'e çevrilen kartta → 172.125. `content-visibility` etkisiz (kaldırınca da 0).
2. **F-106-1b — Invidious `/vi/` proxy bozuk:** `invidious.f5.si` `/api/v1/popular` veriyor ama `/vi/<id>/mqdefault.jpg` **200 + text/html** dönüyor; img'ye HTML basılıyordu. Diğer instance'lar 401/403. Stats endpoint sağlık kontrolünü yanıltıyor.
3. **F-106-2 — Seri failover yavaşlığı:** Çalışan tek instance (f5.si) listede sondan bir önceydi → 4 instance'ın 401/403 timeout zinciri.
4. **F-106-3 — TV auth yoktu:** `openYoutubeLogin` client yoksa `ytClientView` (Google Cloud OAuth formu) açıyordu — sıfır-kurulum giriş imkânsızdı.
