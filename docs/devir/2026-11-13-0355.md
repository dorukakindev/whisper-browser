## Uygulama

- Stremio → **Bulut kütüphanesi** → TorBox Torrents/Usenet/WebDL. Kişisel liste **Listem** olarak ayrı kalır. **Yenile** taşıma önbelleğini atlar; tamamlanmayı sağlayıcıdan yeniden sorgular, kendiliğinden indirme başlatmaz.
- TorBox dosyaları, sezona/bölüme zorlanmadan ortak film detayında listelenir. Dosya seçimi kaynak seçiciyi açar; otomatik oynatmaz. `available:false` dosya seçilemez; bilinmeyen durum cached diye uydurulmaz.
- Gerçek eklenti `meta.videos[].streams` veriyor. Bounded ana süreç köprüsü (12 metadata, toplam metadata başına en çok 400 kaynak, 10 dakika), özel adresleri renderer metadata/liste DTO'suna çıkarmaz. Ebeveyn/eklenti/dosya bağları, yenileme, değişen yapılandırma, geç/çakışan yanıt ve eski oynatma tokenları doğrulanır. Eklenti kapatma/kaldırma/yeniden kurma/geçerlilik süresi eski bağı iptal eder.
- Kaynak etiketi açıkça `[TB+]` benzeri ise cached ipucu, `[TB download]` ise bekleyen indirme ipucu kullanılır; genel HTTPS adresi anında hazır sayılmaz. Bu etiketler TorBox API üzerinden bağımsız cache kanıtı değildir. Bekleyen kaynak Whisper'a verilmez.
- Oynatıcı/Çift dilli/Podcast içinde **Ses / Altyazı** düğmeleri aynı Stremio panelini açar. HLS sesi mevcut canonical select/change yoluna, etkin native ses/altyazı mevcut mpv komutuna, HTML izleri mevcut motor nesnesine gider. Kaynak/nesil/panel sahibi değişen callback çalışmaz. Native aid/sid yalnız mevcut doğru türde pozitif güvenli tamsayı ID kabul eder.
- Gömülü altyazı seçimi özel altyazı katmanını kapatır; eklenti altyazısı seçimi gömülü izi kapatır. Mevcut metin/ofset verileri korunur. Chromium'un göstermediği gömülü izler uydurulmaz; uygun native motor gerekir.
