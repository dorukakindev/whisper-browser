## Kullanım

1. **Gelişmiş ayarlar → Çeviri** bölümünü açın.
2. **Endpoint (rota)** alanında **4SAPI · GPT-5.4 / Gemini 3.8 Flash** seçin.
3. Bu sağlayıcının API anahtarını girin. Anahtar yalnız 4SAPI profilinde saklanır; başka sağlayıcıya geçince o sağlayıcının daha önce kaydedilmiş anahtarı gösterilir.
4. Altyazı profili otomatik olarak `gpt-5.4`, manga profili otomatik olarak `gemini-3.8-flash` seçer. İstenirse iki model alanı da elle değiştirilebilir.
