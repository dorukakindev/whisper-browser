# Handoff — 2026-09-17 07:17 · English default UI and EN/TR switch

## Summary

The main interface now opens in English by default and provides an EN/TR selector in both the main header and the player/browser header. The former **İzle** action is now **BROWSER** and opens the browser workspace directly. The adjacent movie/series archive is presented as a separate **Media library** destination with a filmstrip icon instead of looking like a third player mode.

## Changes

- `src/renderer/ui-locale.js`: English/Turkish interface dictionary, default-English boot, DOM updates for dynamic interface copy, language persistence support, and exclusions for subtitles, media titles, notes, chat and file/user data.
- `src/renderer/index.html`: English document language, BROWSER action, redesigned Media library entry, and EN/TR selectors in both headers.
- `src/renderer/styles.css`: accessible and responsive language/library controls using the existing graphite/amber design system.
- `src/renderer/renderer.js`: persisted locale wiring and direct browser opening without loading the last local-media job as a side effect.
- `src/renderer/media-catalog.js`: populated library cards and episode metadata use the active locale; an open library rerenders on language changes.
- `src/settings-security.js`: `uiLocale` is validated as `en` or `tr` and included in the existing secure settings schema.
- `tests/ui-locale.test.js`: translation reversibility, unique keys, static-copy coverage, English HTML wiring and documented path/theme exceptions.
- `tests/electron-ui-locale.smoke.js`: isolated profile verification of English boot, Turkish switching, reload persistence, user-data protection, player/browser UI, library labels, and screenshots.
- `tests/settings-security.test.js`: validated locale settings roundtrip.
- `README.md`, `CONTRIBUTING.md`, `AGENTS.md`: public and contributor guidance updated to the bilingual interface contract.

## Limits and follow-up

- Static HTML copy and the primary main/player/browser/library surfaces are localized. Older runtime-generated logs and some diagnostic/status messages in large legacy JavaScript/Python paths can still appear in Turkish. This is documented openly rather than claimed as complete whole-product localization.
- Directory names `GİRDİ` and `ÇIKTI` remain unchanged because they are real filesystem paths and translating their display would misrepresent the configured locations.
- No dependency, storage-version, IPC-permission or subtitle-file schema change was introduced.
