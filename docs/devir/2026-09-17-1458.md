## Confirmed defects and root causes

### 1. Missing context at progressive Whisper boundaries

Long browser/video transcription jobs used exact adjacent windows. An utterance crossing the 600-second cut could lose a word or be split incorrectly. The progressive refresh path also accumulated keyed cues rather than replacing stale cues in the refreshed range.

The fix adds four seconds of bounded overlap and applies the existing range-aware replacement operation before rebuilding the translated cue map.

### 2. Complete translation with incorrect cue ownership

Sentence protocol v2 could confirm that a full translated sentence retained the source meaning while still allowing a predicate or sentence-ending mark to move into the wrong timed cue. The new protocol v3 rejects premature target sentence endings on non-final source fragments. The check runs for cached replies, fuzzy memory replies, first provider replies, and refine replies. Both translation prompts describe the same rule.

### 3. Rolling ASR hypotheses and misleading CPS status

Two adjacent growing hypotheses in the latest real output survived as separate cues. A conservative cleanup stage now reconciles only a long shared-word run with strong overlap and an adjacent time range. Exact intentional repetition, speaker boundaries, and SDH/effect cues remain untouched.

The timing log now calls configured CPS a target rather than a guaranteed maximum, uses `CPS` consistently, and emits an explicit warning for remaining violations.
