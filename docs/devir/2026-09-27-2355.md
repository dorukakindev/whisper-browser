### Doğrulanmış bug sınıfı: sınırsız gövde okuma

`res.text()`/`res.arrayBuffer()` gövdenin tamamını belleğe alır — ardından yapılan
`length > sınır` kontrolü "sonradan budama"dır; `content-length` beyanı da sunucu
kontrolündedir. 5 yüzey akış-sınırlı okumaya çevrildi:

- `main.js` `subs:rssFeed`: `res.text()`+slice → `readResponseBufferLimited` (256K)
- `main.js` altyazı indirme: `arrayBuffer()`+post-check → `readResponseBufferLimited`
  (`EBROWSER_UNSAFE_RESPONSE` eşlemesi; abort + gerçek ağ hataları sınıf değiştirmez)
- `main.js` görseli kaydet: `arrayBuffer()`+post-check → `readResponseBufferLimited` (50 MB)
- `main.js` favicon: `arrayBuffer()`+post-check → `readResponseBufferLimited` (256K)
- `catalog-discovery.js` TMDB `request` + `catalog-extensions.js` afiş: yeni modül-içi
  `readLimitedBytes`/`readTextLimited` (akışta byte sayımı, `reader.cancel`, `releaseLock`;
  `getReader` yoksa `arrayBuffer`/`text` yedeği — test mock'ları için)
