## Ne yapıldı

Yeni tekrarlanabilir kabul harness'i yazıldı ve tam koşusu yapıldı:

- `tools/release-acceptance.js` — dört aşamalı kampanya:
  - **Korpus:** gTTS ile ~5.25 dk sentetik İngilizce konuşma (10 çeşitli cümle × 5 tur; sayı/tarih/özel ad/aksan/işaret içeren satırlar) + 8 fixture'lık zor SRT korpusu (SDH, sayı/para/birim, CJK+RTL, uzun satır, entity, örtüşen zaman, kenar zaman (0 ve +1sa), boş cue).
  - **A — transcribe:** tiny/CPU; `/usr/bin/time -v` ile duvar + tepe RSS; BOM doğrulaması (SRT `utf-8-sig` zorunlu, **VTT BOM'suz** — spec), monoton zaman, referansla kelime örtüşmesi.
  - **B — translate:** süreç-içi stub OpenAI sağlayıcısı (`127.0.0.1:<rastgele>`), `sentence_groups` payload sözleşmesine tam uyar (`items=[{i,max,t}]`, `ids` pozisyon; `{sentences, items, memory}` yanıtı). Stub parçaları çapa tokenlarını korur — backend'in echo/anlam/özel-ad kapılarını geçer.
  - **C — edit→save→reopen:** 3 cue düzenleme + bütünlük doğrulama.
  - **D — korpus matrisi:** her fixture'a translate-only; çıktı satırı `acceptance.json` + `RELEASE_ACCEPTANCE.md`'de.
  - `--keep-tmp` ara çıktıları saklar; aksi durumda tmp temizlenir.

## Oturumda giderilen engeller (harness geliştirme)

1. **Deadlock:** `spawnSync` event loop'u dondurur; süreç-içi HTTP stub backend isteklerini cevapsız bıraktı (ss recv-Q kanıtı). `runBackend` async `spawn`'a çevrildi; araç içine kalıcı uyarı yorumu kondu.
2. **`--translate-only` değeri literal `true` olmalı** (argparse `type=lambda x: x.lower()=="true"`).
3. **VTT BOM:** spec yasaklıyor — beklenti tersine çevrildi.
4. **Stub↔sözleşme uyumu:** echo kapısı → `TR-i ... çeviri` biçimi; `part_kapisi_ozel_ad_*` → tüm özel adlar (kesme/tire dahil) korunur; `anlam_*` → sayı/para/birim/tarih/ay-adı + olumsuzluk/modal çapaları.
