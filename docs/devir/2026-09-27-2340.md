### Tasarım notları

- **Gizlilik:** DeArrow, SponsorBlock ile aynı hash-öneki modeli — ham video
  kimliği değil sha256'nin ilk 4 karakteri gider; RYD'de video-id doğrudan
  gerekir (servisin sözleşmesi).
- **Hata modeli:** ağ hatası `ok:true` + alan başına `error` dizgisi döner;
  oynatıcı açılışını bozmaz. SponsorBlock fetch duruşu birebir kopyalandı
  (credentials:'omit', redirect:'error', timeout/abort, size cap).
- **Stale koruması:** yanıt `videoId` hem gönderilenle hem o an açık
  medyayla (`mediaKey.includes` veya ytInfo.sourceUrl/originalUrl) eşleşmeli.
- **Başlık seçimi:** DeArrow'da orijinal başlık asla uygulanmaz; kilitli
  özgün-olmayan önce, yoksa en yüksek oylu (bağ: localeCompare).

### Düzeltilen uygulama-içi kusurlar

1. DeArrow hash-öneki yanıtındaki yanlış-video başlığı uygulanması → videoID
   süzmesi.
2. Sanitizer regex'inde bayt-düzeyi kaçış bozulması (kontrol char aralığı
   literal bayta dönüşmüştü) → python bayt düzeltmesi + test.
3. RYD sahte yük (başka id'li yanıt) → id eşleşme kapısı.
4. settings-security kalıcılık sırası → renderer listesiyle bire bir.
