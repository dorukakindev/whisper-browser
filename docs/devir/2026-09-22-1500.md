- **`src/renderer/styles.css`** — `:root`~`html` köprü alias bloğu eklendi:
  ```css
  html {
    --fg: var(--text);
    --muted: var(--text-muted);
    --bg: var(--bg-1);
    --bg-sunken: var(--bg-3);
  }
  ```
  `.st-*`/`.inv-*`/`.yt-*` katmanları dosyada 47+ yerde bu eski palet adlarını kullanıyor ama hiçbiri tanımlı değildi — kanonik token refaktöründe (`--text`/`--text-muted`/`--bg-*`/`--surface-*`) blok atlanmış. Tanımsız `var()` geçersiz → `inherit`'e düşüyor; SmartTube katmanı player-stage'in koyu-zemin metin rengini `rgb(240,240,242)` miras alıyordu. Açık temada krem zemin üstünde başlık/kanal adı/sidebar etiketleri/öneri listesi/Invidious modalı hepsi görünmezdi. Koyu temada tesadüfen okunaklıydı — hata bu yüzden gizli kalmış.
  - `html` seçici kasıtlı (`:root` değil): `tests/renderer-state-a11y-responsive.test.js` kontrast testi kaynaktaki **son `:root` bloğunu** regex'le okuyor; alias `:root` olsaydı test patlıyordu (doğrulandı — ilk denemede TypeError aldı, `html` ile hem test hem görünüm geçti).
  - `var()` kullanım yerinde çözüldüğü için `html[data-theme="light"]` geçersiz kılmaları otomatik doğru değer verir; iki tema için ayrı blok gerekmez.
