## Yeni kesin bulgular (4)

### B-108-30 [P2] `browser-feature-services.data()` bozuk JSON'da bellekteki mevcut kayıtları da sıfırlıyor

B-108-11'in daha derinine inen katman. `data()` `try { skipData = JSON.parse(...) }
catch { skipData = {} }` ile parse hatasında boş set atıyor; ardından her durumda
`skipData = { records: normalizeRecords(skipData?.records), series: ... }` ile
normalize edip records/series'i `[]`/`{}` döndürüyor. Normal `add` çağrıları bu
önbelleği kullanır; `save()` boş cache'i diske yazar. Bozuk JSON dosyası
kullanıcı bildirimi almadan, loglanmadan ve `.bak` yedeğine düşmeden kaybolur.
`_repro/r108-skip-data-loss.js` kanıtladı: 1 record + 1 series → bozuk JSON →
0 records + 0 series → kalıcı kayıp.

### B-108-31 [P2] `translationSchedulerBusy` `retryTimers.size`'ı hâlâ görmüyor — B-108-16'nın deterministik reproduksiyonu

İlk turda "private retryTimers set edilmiş olabilir" diye belirsiz kalan
B-108-16, üçüncü turda kesin kanıtlandı. `_repro/r108-scheduler-busy.js`:
1 cümle gönderildi, `translate` her çağrıda `{ httpStatus: 429, retryable: true }`
reddetti, `maxAttempts=10` ile retry timer kuruldu. 200ms sonra `snapshot()`:
`pending=0, queued=0, failures=1 retrying, retryTimers.size=1`. Ancak
`translationSchedulerBusy` yalnız `pending+queued`'a bakıyor → `false`.
`browserTabUnloadDecision` "güvenli" der, sekme unload edilir, retry timer
scheduler'da asılı kalır. `snapshot()` `retryTimers`/`providerFailure`/`idleWaiters`
bilgilerini dışa çıkarmıyor.

### B-108-32 [P2] `SafeSecretStore.save()` partial-decrypt deadlock riski — kalıcı API anahtarı kaybı

`save()` içinde `this.fs.existsSync(this.filePath) && this.loadFile(this.filePath).ok`
koşulu yalnız **decryptable** dosyaları yedekliyor. `current.partial: false, ok: false`
durumunda (örn. macOS safeStorage encryption scheme'i OS upgrade sonrası değişti):
- `saveFromSettings` `current.partial: true`'da erken return eder (veri korunur),
- ama `current.partial: false, ok: false`'da erken return etmez, `save(next)`
  çağrılır, `save()` anahtar deposu dosyasını yenisiyle değiştirir.
- Bozuk ama kurtarılabilir ana dosya kalıcı olarak kaybolur.

### B-108-33 [P3] `browser-translation-archive._writeText` rename başarısızsa temp temizlenmiyor + sayfa arşivi yarı tutarsız state

`_saveIndex` hata durumunda `temp` dosyasını silmiyor; `_writeText` da aynı
durumda temp'i bırakıyor. Nadir ama disk dolu/izin reddi senaryolarında
yetim temp dosyaları birikir ve `_writeText` `wx` flag'i kullanmadığı için
atomicity kırılır. `_saveIndex` finally/cleanup içermiyor.

## False positive kanıtı (1)

### B-108-19 [YANLIŞ POZİTİF] `discoverMedia` "her render'da sort" iddiası

Kodun yeniden okunmasıyla `discoverMedia`'nın `if (!mediaDirty && media &&
media.isConnected) return media;` guard'ı içerdiği görüldü. `activity()`
callback'i yalnız `play`/`pause`/`loadedmetadata`/`emptied` olaylarında
`mediaDirty = true` yapar; salt `seeked`/`ratechange`/`timeupdate` gibi sık
olaylar dirty flag'i tetiklemez. `_repro/r108-discover-media-test.js` 1000
ardışık render'da yalnız 0-1 sort yapıldığını gösterdi. **YANLIŞ POZİTİF**
olarak rapordan çıkarıldı.
