## Yeni Tespit Edilen Buglar (R93 Serisi)

### P1 — Kritik

#### R93-01: `normalizeBrowserEventContext(null)` throw ediyor
- **Dosya:** `src/browser-event-envelope.js:8`
- **Kök neden:** `function normalizeBrowserEventContext(raw = {})` — default parametresi sadece `undefined` için geçerli, `null` için değil. `null.tabId` erişimi `TypeError` fırlatıyor.
- **Kanıt:** `tests/r92-deep/adversarial-fuzz-v2.test.js`
- **Etki:** IPC handler'larından `null` context gelirse tüm işlem çöker. `createBrowserEventEnvelope(null)` çağrıları zincir şeklinde başarısız olur.
- **Test çıktısı:**
  ```
  BUG   [R93-01] normalizeBrowserEventContext(null) throws
        Null context ile TypeError: Cannot read properties of null (reading 'tabId')
  BUG   [R93-01b] createBrowserEventEnvelope(null) throws
        Null context ile TypeError: Cannot read properties of null (reading 'tabId')
  ```
- **Fuzz:** 50 rastgele input'tan ~%10'u (null) throw etti.

#### R93-04: `normalizeCues` NaN/Infinity times kabul ediyor
- **Dosya:** `src/browser-translation-scheduler.js:10-20`
- **Kök neden:** `Math.max(0, finiteNumber(cue && cue.start))` — NaN için `Math.max(0, NaN) = NaN`. Filtre `cue.end >= cue.start` ile NaN karşılaştırması her zaman `false` döndürmesi gerek AMA sıralama `a.start - b.start` NaN davranışı sergileyip sort'u bozuyor.
- **Kanıt:** 
  ```
  BUG   [R93-04] normalizeCues accepts NaN times
        NaN start/end olan cue filtrelenmedi → sort bozulur
  BUG   [R93-04b] normalizeCues accepts Infinity times
  BUG   [R93-04c] normalizeCues accepts -Infinity times (clamped to 0)
        Negative infinity 0'a clamp olur ve 0 >= 0 = true ile geçer — geçersiz veri sızıntısı
  ```
- **Etki:** Bozuk zaman damgalı cue'lar downstream'e sızar, cümle sıralaması karışır, çeviri penceresi yanlış hesaplanır.

### P2 — Önemli

#### R93-02: `permissionOrigin` IDN/punycode URL reddediyor
- **Dosya:** `src/browser-site-permissions.js`
- **Kök neden:** `permissionOrigin` fonksiyonu `xn--*` punycode URL'leri (IDN) reddediyor. Türkçe ve diğer Unicode domainler (`https://xn--tr-ua.com` gibi) izin listesine eklenemiyor.
- **Kanıt:**
  ```
  BUG   [R93-02] permissionOrigin rejects IDN punycode
        IDN/punycode URL'leri (xn--*) yanlışlıkla reddediliyor
  ```
- **Etki:** Türkçe/Unicode domainli siteler için "İzin Ver" kararı hiç kaydedilemiyor; her sayfa yeniden izin ister.

#### R93-03: `migrateBrowserSession` v1 → v8 tamamlanmıyor
- **Dosya:** `src/browser-session-store.js`
- **Kök neden:** v1 objesi v8'e migrate olurken `cleanExit` alanı set edilmiyor — boş object `{}` döndürüyor gibi davranıyor.
- **Kanıt:**

  ```
  FAIL  migrateBrowserSession: v1 → v8 with cleanExit field
        Expected values to be strictly equal: 1 !== 8
  ```
- **Etki:** Eski oturumlar (v1-v7) yeni sürüme taşınırken `version` field'ı doğru set edilmiyor; session restore başarısız olur.

#### R93-08: `assembleCueSentences` gap boundary'de cue birleştirmiyor
- **Dosya:** `src/browser-translation-scheduler.js:90-105`
- **Kök neden:** Karşılaştırma `cue.start - previous.end > maxGap` strict greater — gap tam `maxGap` değerindeyken eleniyor.
- **Kanıt:**
  ```
  BUG   [R93-08] assembleCueSentences does not join within maxGap
        gap=0.5, maxGap=1 → 2 sentence oluştu (beklenen: 1)
  BUG   [R93-08b] assembleCueSentences does not join at boundary
  ```
- **Etki:** Aynı cümleyi ifade eden ardışık cue'lar yapay olarak bölünür, çeviri API'sine fazladan istek gider.

#### R93-14: `position` / `duration` clamp sınırı yanlış birimde
- **Dosya:** `src/browser-session-store.js:204-205`
- **Kök neden:**
  ```js
  position: finiteNumber(raw.position, 0, 0, 60 * 60 * 1000),  // 21.600.000
  duration: finiteNumber(raw.duration, 0, 0, 60 * 60 * 1000),  // 21.600.000
  ```
  Position saniye cinsinden saklanıyorsa, max = 21.600.000 saniye = **6000 saat**. Doğru değer `60 * 60` (1 saat) olmalıydı. Birim karışıklığı (saniye mi ms mi) var.
- **Kanıt:**
  ```
  PASS  position: 100 saatlik değer — clamp edilmeli
  PASS  position: Number.MAX_SAFE_INTEGER — clamped to 60 hours
  ```
- **Etki:** Aşırı büyük pozisyon değerleri kabul edilir, UI'da aritmetik taşma riski, persist boyutu şişer.

#### R93-16: `distributeTranslation` boş çeviride throw ediyor
- **Dosya:** `src/browser-translation-scheduler.js:175-185`
- **Kök neden:** `decodeSentenceTranslation` boş metin için `Cümle çevirisi boş veya geçersiz.` hatası fırlatıyor. `distributeTranslation` bu hatayı yakalamadan re-throw ediyor.
- **Kanıt:**
  ```
  FAIL  distributeTranslation: empty translatedText
        Cümle çevirisi boş veya geçersiz.
  FAIL  distributeTranslation: whitespace-only translatedText
        Cümle çevirisi boş veya geçersiz.
  ```
- **Etki:** Sağlayıcı boş çeviri döndürdüğünde scheduler çöker; defensive kod olarak boş array `[]` dönmeli.
