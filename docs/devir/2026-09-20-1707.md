  (`template`, `level`, `width/height`, `count`, `intervalMs`, `columns/rows`).

- **B01 — Yerel videoda seekbar görseli:** `media:seekPreview` IPC'si
  `media:waveform` desenini izliyor — `authorizedBrowserSender` →
  `authorizeLocalMediaPath` → sha256(path|mtime|size|kare) anahtarlı
  bellek+disk önbelleği (`userData/seek-previews/`) →
  `ffmpeg -vf fps=N/duration,scale=160:-2,tile=10x10 -frames:v 1`.
  `mediaJobs.seekPreview` serileştirmesi, 90 sn timeout +
  `terminateProcessTree` iptali. CSP `img-src` `file:` içermediği için JPEG
  `data:` URL olarak dönüyor. Dosya başına tek üretim, renderer tarafında
  `mediaKey` başına en fazla 8 sprite önbelleği.
- Zaman + cue metni tooltip'i (`seekTip`) korunuyor; sprite yoksa davranış
  eskisiyle aynı.
