## Kurulum ve kullanım

Kullanıcı yeni formatlanmış ortamı geliştirmeye hazırlamak istedi. Python kurucu komutu araç politikası tarafından reddedildi; kullanıcı Python 3.11.9'u kendisi kurdu. `py -3.11 --version` ile doğrulandı. Python 3.14 kaldırılmadı. Mevcut Node v26.8.2 / npm 11.19.1 korundu.

FFmpeg'in resmi indirme sayfasında bağlantı verilen Gyan sağlayıcısından `https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip` indirildi; aynı sağlayıcının `.sha256` dosyasıyla SHA-256 eşitliği kontrol edildi. FFmpeg ve ffprobe 9.0.1 çalıştırıcıları `backend/bin` içine kondu, ikisinin `-version` komutu geçti. İndirme/açma dosyaları Windows geçici dizininde kaldı.

`install.bat` içindeki aynı kurucu etkileşimsiz olarak `node tools/install-orchestrator.js core` ile çalıştırıldı, exit 0. Mevcut lockfile ve kurulum kodu kullanıldı; sürüm yükseltmesi veya şema değişikliği yapılmadı. Ana paketler: pip 25.1.1, torch/torchaudio 2.5.1+cu121, faster-whisper 1.2.1, ctranslate2 4.4.0, yt-dlp 2026.7.4, cuBLAS 12.1.3.1, cuDNN 9.1.0.70, openai 1.109.1, genanki 0.13.1, castlabs-evs 1.3.2. Electron ve Node paketleri `npm ci` tabanlı mevcut akışla kuruldu. Tam yerel Python manifesti ignore edilen `backend/install-state.json` içindedir; SHA-256: `b5dc3887dc3fc8d30ac1073fe22921ac5c6e6c476dc0b848b24887270fa3374b`.

Kurucu ikinci kez çalıştırılınca `IDEMPOTENT_SKIP` ve exit 0 verdi. Uygulama normal kullanımda DLL/PATH hazırlığı için yine `start.bat` ile açılmalı. WhisperX/diarization opsiyonel profilleri kurulmadı, model indirilmedi, EVS hesabı/imza işlemi yapılmadı.

## Doğrulama

- `backend/venv/Scripts/python.exe -m pip check`: geçti.
- Aynı Python ile `torch`, `faster_whisper`, `ctranslate2` importları: geçti. `torch.cuda.is_available()` False. Ortamda VMware SVGA 3D / Microsoft Remote Display Adapter görüldü; NVIDIA GPU doğrulanmadı.
- `npm test`: **193 dosya, 191 başarılı, 2 başarısız**, exit 1. Komut sürecinin PATH'ine `backend/bin` ve `backend/venv/Scripts` eklendi; global PATH değiştirilmedi.
- Başarısızlar: `tests/browser-stream-fixtures.test.js` localhost `ECONNREFUSED`; `backend/test_ytdlp_update.py` localhost WinError 10061, 16 test içinde 12 error. Önceki ortam engelleri otomatik atlanmadı, testler gerçekten çalıştırıldı.
- Önceden bağımlılık yüzünden başarısız olan `backend/test_export_anki.py`, `backend/test_ffmpeg_integration.py`, `backend/test_transcribe.py` bu koşuda geçti.
- `npm run test:electron-bridge`: geçti; gerçek Electron köprü/medya/shadow/iframe ve Dark Reader kontrolleri.
- Venv Python ile `-m py_compile backend/transcribe.py`, `node --check src/main.js`, `src/preload.js`, `src/renderer/renderer.js`: geçti.
- Tam uygulama `start.bat` ile açılmadı; canlı site, uzun video, model transkripsiyonu ve ücretli sağlayıcı testi yapılmadı. GPU başarısı iddia edilmiyor.
- Yerel test günlükleri `.uiprev/setup/` içinde, Git kapsamı dışında.
