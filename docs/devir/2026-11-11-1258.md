## Kanıt

- Kişisel profil kullanmadan izole, görünmez gerçek Electron'da halka açık https://torrentio.strem.fun/configure yüklemesi ERR_CONNECTION_REFUSED (-102) verdi.
- Aynı testte https://example.com açıldı. Geçici session.setProxy({mode:'direct'}) ile Torrentio sonucu değişmedi; sistem proxy çözümü de DIRECT idi.
- Sistem DNS A yanıtları 188.114.97.7 / 188.114.96.7; açıkça 1.1.1.1 sorgusunda 104.21.10.254 / 172.67.164.220. hosts dosyasında Torrentio kaydı bulunmadı.
- Yalnız geçici test Electron sürecinde host-resolver-rules ile torrentio.strem.fun → 104.21.10.254 eşlemesi uygulandı. Aynı gerçek configure sayfası yüklendi, gövdede INSTALL bulundu. TLS doğrulaması kapatılmadı; sistem DNS'i ve ürün değiştirilmedi. Sabit IP kalıcı çözüm değildir.
- Ayrı web erişimi de gerçek configure ve manifest sayfasını okuyabildi. Bu kullanıcı ağından yapılan testle karıştırılmaz.
- İlk tanı harness'i pencere kapanınca erken kapandı; window-all-closed yaşam döngüsü düzeltilerek sistem/direct karşılaştırması eksiksiz tamamlandı. İlk eksik çıktı tek başına başarı sayılmadı.

Sonuç: bu makinenin DNS yanıt yolu Torrentio erişim hatasını yeniden üretiyor; alternatif DNS yanıtıyla aynı sayfa açılıyor. Yanıt farkının aktörü veya engelleme nedeni belirlenmedi. Debrid hesabı/anahtar/kişisel manifest okunmadı; film başlatılmadı.
