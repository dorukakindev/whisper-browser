## Kapsam

Plan maddesi "subs:shift UI E2E": sonuç modalı zaman kaydırma aracının
gerçek Electron'da uçtan uca sözleşmesi. Zincir: UI tıklaması
(`#applyShift`) → `pickOutput` → `window.api.shiftSubs` → `subs:shift`
IPC → `authorizeSubtitleFile` onay diyaloğu → `shiftTimecodes` →
`backupOnce` (.bak) → `writeSubtitleAtomic` → log satırı.

## Değişiklik

- `tests/electron-subtitle-shift.smoke.js` (yeni): Electron-main smoke
  kalıbında (`require('../src/main.js')` + `dialog.showMessageBox` stub'ı)
  5 senaryo:
  1. +1.5s kaydırma — zaman kodları doğru, `.bak` orijinali korur,
     onay diyaloğu kayıtlı, başarı logu.
  2. Onay reddi — ayrı (yetkisiz) dosyada diyalog reddedilir, dosya
     değişmez, `Kaydırma başarısız … onaylanmadı` logu.
  3. Geçersiz girdi (`abc`) — IPC'ye çıkmadan uyarı, diyalog yok.
  4. Altyazısız çıktı listesi — `Kaydırılacak SRT/VTT çıktısı yok`, IPC yok.
  5. Negatif kaydırma (−3.6s) — tamamen 0 öncesine kayan blok budanır,
     kalan blok 0-kelepçeli kayar.

`tests/run-electron-smokes.js` dosya adıyla otomatik keşfeder; `--all`
setine dahil (ağ/gerçek sağlayıcı gerektirmez).
