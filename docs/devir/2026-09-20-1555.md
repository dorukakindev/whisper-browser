### KRİTİK BUG (P1)

#### R92-01: `browser-fonts.js` `finally` Bloğunda Throw — Orijinal Hata Maskeleniyor
**Dosya:** `src/browser-fonts.js:33-36`
**Tür:** Mantık Hatası + Kaynak Sızıntısı
**Öncelik:** **P1**
**Açıklama:** `extractFonts()` fonksiyonunun `finally` bloğunda `throw new Error(...)` yapılıyor. Eğer `try` bloğu bir exception fırlattıysa (örneğin `ffmpeg` hatası, `readFonts` validation hatası), `finally` içindeki bu throw orijinal hatayı maskeleyerek kullanıcıya yanlış bir hata mesajı gösterir. Ayrıca `fs.rmSync(dir, ...)` çağrısından sonra yapılan throw nedeniyle klasör silinmeden önce exception fırlatılabilir.
**Kanıt:**
```js
async function extractFonts(video, ffmpeg, ffprobe, signal) {
  // ...
  const dir = fs.mkdtempSync(path.join(os.tmpdir(), 'whisper-fonts-'));
  try {
    // ... ffmpeg işlemleri ...
    return readFonts(files);
  } finally {
    // SORUN: Burada throw finally bloğunda — orijinal hatayı maskeler
    if (path.dirname(path.resolve(dir)) !== path.resolve(os.tmpdir())
        || !path.basename(dir).startsWith('whisper-fonts-')) {
      throw new Error('Geçici font yolu geçersiz.');
    }
    fs.rmSync(dir, { recursive: true, force: true });
  }
}
```
**Ek Sorun:** `path.dirname(path.resolve(dir)) !== path.resolve(os.tmpdir())` kontrolü her zaman FALSE döner çünkü `mkdtempSync` zaten `os.tmpdir()` içinde oluşturuyor — bu kontrol anlamsız.
**Etki:** ffmpeg başarısız olduğunda kullanıcı "Geçici font yolu geçersiz" hatası görür, gerçek hatayı göremez. Geçici klasör silinemez (kaynak sızıntısı).
**Önerilen Düzeltme:** `finally` bloğundaki throw kaldırılmalı, klasör silme `try { fs.rmSync(...) } catch {}` içine alınmalı.

#### R92-02: `browser-session-store.js` `persistedMediaId` Split Mantık Hatası
**Dosya:** `src/browser-session-store.js:175-180`
**Tür:** Mantık Hatası
**Öncelik:** P2
**Açıklama:** `normalizeSessionTab()` içinde `persistedMediaId.includes(':url:')` kontrolü yapılmadan, `persistedMediaId.split(':')` ile parçalara ayrılıyor. Eğer `mediaId` `:` içeren bir service kimliği içeriyorsa (örn. `service:contentId:more:stuff`), yanlış parçalara ayrılır ve `persistedParts.length > 1` koşulu tetiklenir.
**Kanıt:**
```js
const persistedMediaId = cleanString(raw.mediaId, 240);
const persistedParts = persistedMediaId && !persistedMediaId.includes(':url:')
  ? persistedMediaId.split(':') : [];
const identity = canonicalMediaIdentity(url, {
  service: raw.service || (persistedParts.length > 1 ? persistedParts[0] : ''),
  contentId: raw.contentId || (persistedParts.length > 1 ? persistedParts.slice(1).join(':') : ''),
});
```
**Etki:** Eski oturum geri yüklemede `service` ve `contentId` yanlış parse edilir, medya kimliği eşleşmesi bozulur.
**Önerilen Düzeltme:** `:url:` ayracı daha güvenilir bir format ile değiştirilmeli veya `persistedMediaId` zaten canonical format ise split yapılmamalı.

### ORTA ÖNEMLİ BUGLAR (P3)

#### R92-04: `atomic-json.js` Temp Dosya Çakışma Riski
**Dosya:** `src/atomic-json.js:11`
**Tür:** Race Condition (Teorik)
**Öncelik:** P3
**Açıklama:** `writeJsonAtomic()` içinde temp dosya adı `${filePath}.${process.pid}.tmp` — aynı process içinde aynı dosyaya iki eşzamanlı yazım yapılırsa çakışma olabilir. Node tek thread'li çalışsa da, async I/O sırasında ikinci çağrı birincinin tamamlanmasını beklemeden başlayabilir ve ikinci temp dosyası birincinin üzerine yazabilir.
**Kanıt:**
```js
const tmp = `${filePath}.${process.pid}.tmp`;
```
**Önerilen Düzeltme:** Benzersiz bir sayaç veya UUID eklenmeli (örn. `${process.pid}-${Date.now()}-${counter}`).

#### R92-05: `secret-store.js` `redactExport` Case-Sensitive
**Dosya:** `src/secret-store.js:31-37`
**Tür:** Güvenlik (Düşük Risk)
**Öncelik:** P3
**Açıklama:** `redactExport()` regex'i `/(?:api[_-]?key|token|...)$/i` — `i` flag'i ile case-insensitive. Ancak bu sadece anahtar adının SONUNDA bu kalıpları arar. Ortada geçen (örn. `myApiKeyBackup`) yakalanmaz.
**Kanıt:**
```js
&& !/(?:api[_-]?key|token|password|passwd|secret|authorization|cookie|credential)$/i.test(key))
```
**Etki:** `myApiKeyBackup`, `tokenServiceUrl` gibi anahtarlar dışa aktarımda sızabilir.
**Önerilen Düzeltme:** Regex `(?:...)$` yerine `(?:...)` ile sonu zorunluluğu kaldırılmalı veya `\\b` word boundary kullanılmalı.

#### R92-06: `browser-transcript-search.js` `fold()` CJK Katlaması
**Dosya:** `src/browser-transcript-search.js:7-12`
**Tür:** Mantık Hatası (Edge Case)
**Öncelik:** P3
**Açıklama:** `fold()` fonksiyonu `replace(/[\u0300-\u036f]/g, '')` ile sadece Combining Diacritical Marks aralığını temizliyor. Türkçe `İ` (U+0130) tek başına bir harf olarak bu aralıkta değil, bu yüzden NFKD sonrası `i + ̇` oluşur, sonra diacritic temizlenir → `i`. Ancak `replace(/[Iİı]/g, 'i')` zaten bu harfleri yakalıyor, fazlalık oluşuyor. Performans açısından küçük bir israf.
**Kanıt:**
```js
return String(value || '').normalize('NFKD').replace(/[\u0300-\u036f]/g, '')
  .replace(/[Iİı]/g, 'i').toLowerCase()
  .replace(/[^\p{L}\p{N}]+/gu, ' ').trim();
```
**Etki:** Yok — sadece gereksiz bir replace.

#### R92-07: `browser-translation-scheduler.js` `normalizeCues` `end` Hesabı
**Dosya:** `src/browser-translation-scheduler.js:11-13`
**Tür:** Mantık Hatası (Edge Case)
**Öncelik:** P3
**Açıklama:** `end` hesaplanırken sadece 0 ile max yapılıyor, `cue.start` ile değil. Eğer `cue.end = -5, cue.start = 10` gelirse end = 0 döner ama filter `0 >= 10` FALSE döndürerek eler — bu doğru. Ancak `cue.end = NaN, cue.start = 10` durumunda `Math.max(0, NaN) = NaN` döner ve filter `NaN >= 10` FALSE döndürür — yine elenir. Edge case'ler doğru ele alınıyor.
**Önerilen Düzeltme:** Gerek yok — mevcut filter doğru çalışıyor.

#### R92-08: `browser-mini-player.js` `close()` Event Tekrarı
**Dosya:** `src/browser-mini-player.js:39-51`
**Tür:** Race Condition (Teorik)
**Öncelik:** P3
**Açıklama:** `close()` event listener'ı `currentTab`'a erişiyor, ama `window = null` ataması listener içinde yapılıyor. Eğer event iki kez tetiklenirse (Electron'da nadir), ikinci çağrıda `currentTab` zaten `null` olabilir. `window !== currentWindow` kontrolü var, ama bu sadece window referansını kontrol ediyor, event tekrarını değil.
**Kanıt:**
```js
window.on('close', () => {
  if (window !== currentWindow) return;
  try { currentWindow.contentView.removeChildView(currentTab.view); } catch (_) {}
  window = null; tab = null;
  // ...
});
```
**Önerilen Düzeltme:** Listener'ı `once` ile bağla veya bir `closed` flag'i ekle.
