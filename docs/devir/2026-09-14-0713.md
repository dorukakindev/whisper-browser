## Kök neden ve doğrulama

Sohbet tercihleri yeni Codex oturumuna otomatik taşınmayabilir; bilgisayara özgü araçlar ve ignore edilen dosyalar Git clone ile gelmez. Tercihler kök `AGENTS.md` içine, kurulum/devralma akışı bağlantılı rehbere taşındı. Eski upstream bağlantılarının yanlış push hedefine yol açmaması için gerçek teslim deposu ayrıca belirtildi.

Kurulum bilgileri `install.bat`, `start.bat`, `tools/install-orchestrator.js`, `package.json`, `.gitignore` ve `src/main.js` içindeki userData kullanımları okunarak doğrulandı: Node alt sınırı 22.13; kurucu Python 3.10/3.11 bekliyor; FFmpeg/ffprobe önkoşul; üretim başlangıcı DLL PATH'i için start.bat üzerinden. Bunlar mevcut kaynak kodunun gereksinimleridir; temiz Windows kurulumunda bu görevde denenmiş değildir.

## Kullanım

Yeni bilgisayarda repoyu klonla, klasörü Codex'te aç ve `YENI-BILGISAYAR.md` sonundaki mesajı gönder. Yeni Codex önce `AGENTS.md`, rehber ve `DEVIR-NOTU.md` güncel bağlantısını okumalı; browser ürün durumunu görmek için [önceki ürün devir notuna](2026-09-14-0657.md) da bakmalıdır. Her not tarihsel kanıttır; güncel Git durumu ve kurulum yeniden doğrulanmalıdır.

## Testler ve yapılmayanlar

- `git diff --check`: geçti.
- PowerShell ile `AGENTS.md`, `YENI-BILGISAYAR.md`, `README.md` içindeki yerel Markdown hedeflerini regex ile çıkarıp `Test-Path -LiteralPath` ile doğrulama: geçti. HTTP ve sayfa içi anchor hedefleri bu dosya kontrolüne dahil edilmedi.
- Yeni devir notu ve kök indeks bağlantıları ayrıca yerel dosya varlığı üzerinden kontrol edildi.
- `npm test`, Electron köprü testi, UI smoke ve Python derleme kontrolü **bu görevde çalıştırılmadı**; yalnız Markdown belgeleri değişti. Önceki çalışmanın 188/193 sonucu yeniden çalıştırılmış bir sonuç değildir.
- Yeni paket indirme/kurma, Windows formatlama, GitHub hesabı açma, kişisel yedek alma, profil geri yükleme veya temiz bilgisayarda uygulama başlatma **yapılmadı**. Kullanıcının gelecek çalışmalar için kurulum yetkisi belgelendi.
