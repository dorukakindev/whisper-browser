# Handoff — 2026-09-17 08:10 · Turkish subtitle comprehension and A/B quality review

## Summary

The browser subtitle translation path now treats natural Turkish as a whole-thought problem instead of forcing every number and proper name to remain inside its original cue. It keeps timestamps and cue count unchanged, allows phrase placement across adjacent parts only inside the same sentence group, performs a silent Turkish grammar/fluency review in the same provider request, and exposes conservative source/target review warnings for measurement.

## Root cause and decisions

- The previous prompt simultaneously asked for natural Turkish word order and required numbers, dates, codes and proper names to stay in the exact source cue. Those requirements conflict when Turkish grammar moves a phrase within a sentence.
- A second provider-side refinement pass would increase latency and token cost and could rephrase already-good translations. The selected design performs a bounded silent self-review inside the existing request instead.
- Automatic terminology is evidence collected from earlier segments, not an explicit user glossary. Treating every learned term as a mandatory fixed translation can choose the wrong sense. The prompt now distinguishes mandatory glossary entries from context-sensitive terminology candidates.
- Source uncertainty and fluency heuristics remain advisory. They do not reject a translation or trigger retry loops.

## Changes

  - Relaxed exact-cue number/name ownership while retaining the same sentence group, temporal neighborhood, cue order and lossless full-text contract.

  - Applies the Turkish review guidance to both grouped and single-cue browser translation requests without another API call.

## Usage

1. Start a fresh full-track translation. Existing completed `.tr.srt` files are not silently overwritten, and the prompt-version bump applies to new translation work.
2. To compare an old and new result against the same source:
   `npm run compare:subtitle-translations -- "source.srt" "old.tr.srt" "new.tr.srt"`
3. Add `--json` for the complete issue-by-issue delta.

## Limits

- No live paid-provider request was made. The request contract, cache invalidation, quality metrics and full application test suite are verified; the exact prose produced by each provider still requires a fresh user translation.
- The heuristics deliberately cover high-confidence mechanical symptoms. They cannot prove that a metaphor, philosophical term or ambiguous sentence has the best Turkish rendering; those remain corpus/human-review questions.
- No dependency, IPC permission or persistent-data schema was added.
