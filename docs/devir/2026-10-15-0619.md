## İstek, sonuç ve kullanım

Kullanıcı YouTube ana sayfa/video reklamları ve reklam engelleyici tespitini bildirdi; GitHub çözümlerini araştırıp gerçek hataları düzeltmemi istedi. Yeni motor yerine mevcut Ghostery 2.18.2 entegrasyonunun çalıştırma hataları düzeltildi. Uygulamayı kapatıp normal start.bat ile yeniden açın, YouTube sayfasını yenileyin; genel reklam koruması açık ve site koruması duraklatılmamış olmalı. Deneysel player-response budama varsayılanı değiştirilmedi; yeni düzeltmeler bu anahtarı açmayı gerektirmez. Çerez/hesap temizleme yapılmadı.

Reklam betikleri ve CSS yükleme bitişini beklemez. Betikler ayrı sözcüksel kapsamda çalışır; JSONPath/helper çakışması ve zincirleme proxy recursion önlenir. İlk filtre indirmesi geç biterse açık ilk sayfa da temel kuralları alır. Çalışan uygulamada filtreler 6 saatte yenilenir; ağ hatasında eski motor korunur. Yeni kuralların açık sayfalarda tam etkisi için yenileme gerekebilir. Görünür Atla düğmesinden önce gizli düğme bulunması artık görünür düğmeyi engellemez.

Kök nedenler, resmî araştırma bağlantıları ve kanıtlar: [rapor 424](../raporlar/BROWSER_BUG_REPORT_424.md).

## Dosyalar

- src/browser-adblock.js: erken senderFrame scriptlet/CSS yolu, ayrı fonksiyon kapsamı, eski belge/site anahtarı koruması; soğuk ilk sayfa uygulanması; 6 saatlik yenileme ve rollback; HTTP/gövde timeout ve atomik motor cache yazımı. Durum updatedAt alanı eklenir, dosya/IPC şeması geçişi yok.
- src/main.js: açık browser sayfalarını controller'a verme ve otomatik yenileme durumunu mevcut adblock-status kanalıyla yayınlama.
- src/browser-media-controller.js: aynı reklam seçicisindeki tüm görünür adayları değerlendirme.
- tests/browser-adblock.test.js: HTTP/gövde timeout, erken frame/CSS, eski URL, yenileme/geri alma/kapalı koruma, geç ilk sayfa regresyonları.
- tests/browser-media-controller.test.js: gizli ilk Atla ve görünür ikinci düğme regresyonu (toplam33).
- tests/electron-adblock.smoke.js: dış ağa çıkmayan gerçek Electron testi; uzun yükleyen kaynak sırasında CSS/scriptlet ve aynı isimli iki bağımlılığın ayrılması. Smoke koşturucusu otomatik keşfeder. Kullanıcı profili kullanılmaz.
- docs/raporlar/BROWSER_BUG_REPORT_424.md, INDEX.md, AGENTS.md ve DEVIR-NOTU.md: bulgu/kanıt ve kalıcı indeksler. Bu not ayrı dokümantasyon commit'indedir.

## Doğrulama

Windows'ta geçti:

```
node tests/browser-adblock.test.js
node tests/browser-media-controller.test.js
node tests/browser-cosmetic-executor.test.js
node tests/browser-script-execution.test.js
node tests/youtube-player-response-pruner.test.js
node tests/youtube-player-response-integration.test.js
node tests/preload-usage-ratchet.test.js
node tests/run-electron-smokes.js electron-adblock
npm run test:electron-bridge
```

main/preload/renderer, adblock/media controller ve smoke JS syntax geçti; backend/venv Python ile backend/transcribe.py py_compile geçti; git diff --check temiz. Tam npm test tekrar çalıştırılmadı. İlk Electron koşusu sandbox IPC erişimi engellendi; yetkili ayrı profilde geçti. Son küçük smoke temp-cleanup düzenlemesi yalnız yol sınırı denetimidir; ürün test sonuçlarından sonra yapıldı, syntax kontrolü yapıldı.

Gerçek resmî filtre indirmesi YouTube için29 scriptlet/1297CSS karakteri verdi. Ara erken-enjeksiyon sürümünde kapsam çakışmasıyla site iskelette kaldı; filtresiz karşılaştırma ve kapsam düzeltmesi sonrası aynı video oynadı. Son gerçek ana sayfa/video kontrolünde enforcement görünmedi, görünür ad-slot0, video readyState4/currentTime12.48/pausedfalse, engellenen istek4. Ekran görüntüsü incelendi. Kontrollü yerel smoke, görünür normal içeriği ve interactive aşamasında iki ayrı helper sonucunu doğruladı. Gerçek YouTube testi aynı controller + ayrı Electron penceresindedir; tam uygulama start.bat UI kabulü veya oturumlu hesap testi diye sunulmaz. Bir oturumda reklam görünmemesi bütün reklam çeşitlerinin engellendiği kanıtı değildir.

Bağımlılık/kurulum değişimi yok; install.bat/start.bat değişmedi. Türkçe/Unicode dosya ve Windows cache rename yolları mevcut Node API'leriyle korunur; GPU/CUDA etkisi yok. Hesap, özel profil, ses veya API anahtarı kullanılmadı/yayımlanmadı. Özel denemeler tmp/adblock-research altında ignore edilir. Ürün dışında kalan eski untracked kullanıcı dosyaları commit'e alınmadı.
