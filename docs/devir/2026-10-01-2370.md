## Bulunan bug — B-376-01 (düzeltildi)

**Kasa yazımı ölü `flush:true` seçeneği kullanıyordu.** `SafeSecretStore.save`
`writeFileSync(temp, payload, {encoding:'utf8', flush:true})` —
`flush` bu API'de yok sayılır (WriteStream seçeneği); üstelik
fsyncFile/fsyncDirectory de yoktu. R281'in "temp fsync → rename →
dizin fsync" töreni bu depoya hiç uygulanmamış (B-375-01 ile aynı
sınıfın ikinci örneği). Güç kesintisinde `secrets.safe.json`
sıfır-bayt kalabilir → şifreli API anahtarları kaybolurdu.

**Düzeltme:** `fsyncFile(temp)` → sağlam-birincil `.bak` kopyası +
`fsyncFileBestEffort` → `renameSync` → `fsyncDirectory(dir)`.
`{flush:true}` kaldırıldı.
