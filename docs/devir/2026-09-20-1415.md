## Bulgular

### Bulgu B90-01: Potansiyel Zaman Aralığı Karşılaştırma Hassasiyeti (DÜŞÜK RİSK)

**Dosya:** `src/browser-series-context.js:128-130`

```javascript
const timed = translations.filter((row) => Number.isFinite(Number(row?.start)) && Number.isFinite(Number(row?.end)))
  .sort((a, b) => Number(a.start) - Number(b.start));
```

**Durum:** Kod çalışıyor, ancak zaman aralığı overlap karşılaştırmasında float hassasiyeti potansiyel edge case oluşturabilir. Mevcut `Math.max(prefixEnd.at(-1) ?? -Infinity, Number(row.end))` yaklaşımı bu riski minimize ediyor.

**Etki:** Düşük — çok nadiren aynı milisaniyede biten çakışan aralıklar yanlış eşleşebilir.

**Öneri:** Zaman aralıklarını `Math.round(time * 1000) / 1000` ile 3 ondalık basamağa yuvarlamak hassasiyeti standardize eder.

### Bulgu B90-02: sentenceEnded() Fonksiyonunda Regex Optimizasyonu Fırsatı

**Dosya:** `src/subtitle-sentence-layout.js:37`

```javascript
if (/(?:\.\.\.|…|[,;:]\s*$|\b(?:and|or|but|because|if|when|while|that|which|who|to|of|for|with|as|than|so|then|ve|veya|ama|çünkü|eğer|şu|ki|ile|için|sonra)\.?\s*$)/iu.test(text)) return false;
```

**Durum:** Fonksiyonel ama karmaşık regex. Alternation'ın ilk dalları (`\.\.\.|…|[,;:]`) her zaman kontrol ediliyor, sonraki `|` dalları yalnızca ilk dallar eşleşmezse değerlendiriliyor.

**Etki:** Minimal performans — bu fonksiyon her altyazı satırı için çağrılsa bile microsecond düzeyinde.
