## Dosyalar / kök nedenler

- `tools/voxcpm2/dub_finish.py`: sayı/para/hız birimi/kısaltma konuşma metni, bkz/örn sonrasında gereksiz nokta düzeltmesi, SPOKEN_TEXT_VERSION.
- `tools/voxcpm2/dub_quality.py`: para anlam kanıtında ortak konuşma normalizasyonu.
- `tools/voxcpm2/dub_plan.py`: SDH filtreleme, skipped sayacı, özgün cue sırasını koruyan SourceCues ve shift_cues. Dış patch'in yanlış cümleye edit uygulayan kimlik kayması giderildi.
- `tools/voxcpm2/dub_timing.py`: tek konuşmacı sınırı yardımcısı; sıradan anlatıcı iki noktasını bölmez, ad parçacıklarını korur.
- `tools/voxcpm2/altyazi_oku.py`: shift sırasında kimlik korunumu ve konuşma hazırlığı sürümüyle cache ayrımı. Bu olmadan eski ses cache'i yeni okunuşları atlıyordu.
- `backend/subtitle_sdh.py`: Türkçe modifier normalizasyonu; ortak çeviri yardımcısındaki yanlış negatif düzeltildi.
- `src/dub-service.js`: skipped IPC; tam marker + yapı kontrollü çıktıyı nonzero exit'te kurtarma; başarı/kalite onayı iddiası yok.
- `src/renderer/dub-generator-ui.js`: atlanan satır durum metni.
- `src/renderer/renderer.js`: normal çeviri lenient tercihini geri getirme.
- `src/renderer/ui-locale.js`: iki yeni EN/TR tanı/durum metni.
- `backend/test_subtitle_sdh.py`, `tests/test_dub_finish.py`, `tests/test_dub_plan_regressions.py`, `tests/test_dub_timing.py`, `tests/dub-service.test.js`, `tests/dub-generator-ui.test.js`, `tests/speech-translation-ui.test.js`: kabul ve veri koruma regresyonları. Bayat plan wrapper'ı **kwargs geçirir; test eşiği gevşetilmedi.
- Rapor520, rapor INDEX, AGENTS sayacı ve kök devir indeksi.

## Kullanım / sınırlar

Mevcut SRT → Ses akışında otomatik etkin. Gerçek parantezli konuşma korunur; müzik/SDH anlatıcıya okutulmaz. Eski edit kimliği doğru cue'da kalır. Konuşma cache protokolü değiştiğinden ilk yeniden üretim daha uzun olabilir, eski cache silinmez. Kurtarılmış hata çıktısı dinlenebilir ve dosya açılabilir; otomatik dublaj başarı kaydı/bağlama yapılmaz. UI yeni ayar gerektirmez.

Test komutları ve sayılar [Rapor520](../raporlar/BROWSER_BUG_REPORT_520.md) içinde; hepsi Windows Node/backend venv ile geçti. Gerçek motor yerine kontrollü motor testleri kullanıldı. Python syntax, JS syntax, locale, diff kontrolleri geçti. Belgeler tamamlanınca docs-index-integrity çalıştırılır. Tam paket/CI beklenmez. Gerçek Electron/GPU/start.bat/YouTube/DRM/sağlayıcı/dinleme yapılmadı; UI yerleşimi değişmedi. Harici VoxCPM2 motoruna dokunulmadı, yeni bağımlılık yok. IPC'ye geriye uyumlu skipped alanı eklendi; schema sürümü değişmedi.

Ana kopyadaki kullanıcı gece raporları/indeks/manifest ve kişisel untracked dosyalar korunur; bu teslimin kapsamı dışındadır. Kod ve dokümantasyon ayrı commit'lerde normal push, PR ve kullanıcının onayıyla merge yapılır; force yok. Uygulama zorla kapatılmaz; yeni kod için yeniden açılış gerekir.
