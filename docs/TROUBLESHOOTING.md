# Troubleshooting

Use start.bat for CUDA/cuDNN errors and rerun install.bat if the environment is incomplete. Update yt-dlp for retrieval failures.

If visible web captions are not captured, start playback, select the language, and inspect subtitle diagnostics. Protected paths may remain inaccessible; Whisper Browser does not bypass DRM. Use local live transcription when no accessible text track exists.

For incomplete translation, compare source and target cue counts, integrity diagnostics, provider errors, and the output file. A finished UI state alone does not prove full coverage.

Reports should include commit/version, Windows, GPU/VRAM, model/engine, source type, steps, and a redacted log. Never include secrets, cookies, private URLs, or copyrighted subtitle files.
