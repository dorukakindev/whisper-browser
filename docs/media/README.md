# Demo media

These assets document the shipped application and its subtitle workflow.

## Application captures

- browser-workspace.png: Electron browser-extras smoke capture using an isolated profile and synthetic browser-extras.test media.
- ai-context-panel.png: controlled Electron AI-context evidence using synthetic page and subtitle data.
- subtitle-editor.png: controlled Electron subtitle-editor evidence using synthetic cue data.

## Real-video translation example

- demo-poster.png and youtube-dual-subtitles.png: a frame from the real-video translation demo with the English source cue in white and the manually reviewed Turkish translation in amber.
- whisper-browser-tour.mp4: a silent 26-second excerpt demonstrating the same dual-subtitle presentation over moving video.
- Source film: [Tears of Steel — official Blender Foundation release on YouTube](https://www.youtube.com/watch?v=OHOpb2fS-cM).
- Media source used to produce the deterministic excerpt: the official tears_of_steel_720p.mov mirror and TOS-en.srt.
- Attribution: Tears of Steel, © Blender Foundation, [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
- The soundtrack is not included. The Turkish subtitle text is a manually reviewed translation prepared for this documentation example.

The shipped application UI inside the application captures is Turkish. No user account, provider credential, private subtitle, API key, or browsing-history data is included.
